## HL-004: format choice, Codex CLI rollout JSONL

**Why Codex.** The source is public and reachable from cloud runs: `raw.githubusercontent.com`
answers, and the repo is pinned to one commit. The OpenCode docs are not reachable from cloud
runs (the Claude Code docs were not either, 2026-11-03). Choosing a format whose source can be
read this session means the format is cited, not recalled.

**Source (openai/codex at commit `444359fa2d71b9313c902c6bd6fd598ed6d8f799`, `main` on 2026-11-03):**
base URL `https://raw.githubusercontent.com/openai/codex/444359fa2d71b9313c902c6bd6fd598ed6d8f799/`
(browse: `https://github.com/openai/codex/tree/444359fa2d71b9313c902c6bd6fd598ed6d8f799`)

Line numbers were taken by the test engineer at that SHA; the builder re-fetched only
`recorder.rs` and the `SessionMeta` struct in `protocol.rs` this run.

**Generate:** `python3 scripts/gen_codex_fixtures.py` (defaults `--seed 4 --out fixtures/codex`).
Output is byte-identical per seed. 30 files, one session each, starting 2026-10-01 (one per UTC day).
The script removes only its own `rollout-*.jsonl` and `README.md` in `--out`.

**Per file:** line 1 is a `session_meta`; then `turn_context`, `user_message`, then 2-6 shell
`function_call` / `function_call_output` pairs (about 20% failures, each followed by an `error`
event), `token_count` events with cumulative and last usage, and optional `CLAIM:` (with or
without `EVIDENCE:`) and `REVIEW-VERDICT: PASS|CONDITIONAL|FAIL` agent messages. `CLAIM:`,
`EVIDENCE:` and `REVIEW-VERDICT:` are harness-lab markers from the frozen test, not Codex features.
